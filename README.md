# BCC-Intern-Assignment-1-on-Portfolio

A personal portfolio website built using **HTML, CSS, and JavaScript** as part of the **BCC Internship Assignment**.

## 📌 Project Overview

This project showcases a personal portfolio website with multiple sections such as home, skills, contact, and project details.  
It is designed to present personal information, abilities, and contact details in a clean and professional web layout.
